# mono

여러 생산성 모듈을 관리하는 개인 워크스페이스입니다.

## 할 일

- 상태와 라벨로 할 일을 분류합니다.
- 마감일, 시간, 메모를 기록합니다.
- 예정된 루틴과 일회성 할 일을 함께 확인합니다.

![할 일](./docs/images/todo.jpg)

## 루틴

- 요일과 종료일을 지정해 반복 루틴을 만듭니다.
- 오늘의 루틴을 완료하고 최근 활동을 확인합니다.

![루틴](./docs/images/routine.jpg)

## 일정

- 월간 보기와 일정표 보기를 전환합니다.
- 시간, 종일, 여러 날, 반복 일정을 기록합니다.
- 사용자 지정 라벨로 일정을 분류합니다.

![일정](./docs/images/calendar.jpg)

## 스크랩

- 메모, 링크, 이미지, 동영상을 한곳에 보관합니다.
- 라벨로 분류하고 댓글로 맥락을 이어갑니다.

![스크랩](./docs/images/scrap.jpg)

## 가계부

- 날짜와 라벨별로 지출을 기록합니다.
- 월별 총액과 라벨별 지출을 한눈에 확인합니다.

![가계부](./docs/images/ledger.jpg)

## 화면

- 앱 전체에 적용할 강조색을 자유롭게 선택합니다.

![강조색 설정](./docs/images/appearance.jpg)
